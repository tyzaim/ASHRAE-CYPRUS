ASHRAE CYPRUS CHAPTER WEBSITE - HOW TO UPDATE
==============================================
(GitHub + Cloudflare Pages)

HOW IT WORKS
Your files live in a GitHub repository. Cloudflare Pages watches it and
republishes the site automatically, usually within a minute or two, each
time you save a change on GitHub. index.html must be at the top level of
the repository.

CHANGING CONTENT
All content that changes lives in ONE file: site-data.js
1. On GitHub, open site-data.js and click the pencil (Edit) icon.
2. Change the text. Instructions and examples are at the top of each section.
   Keep the quote marks "like this" and the commas.
3. Click "Commit changes". The site updates by itself.
Events move to "Past Events" automatically by date.

PHOTOS AND SPONSOR LOGOS
There are no folders. Upload the photo or logo file to GitHub together
with the other site files (Add file > Upload files). File names are
case-sensitive, so use exactly these names for people:
  tamer-zaim.jpg            polyvios-eleftheriou.jpg
  constantinos-zeniou.jpg   nicholas-zachopoulos.jpg
  maria-andreou.jpg         ierotheos-syrigos.jpg
  zacharias-hadjigeorgiou.jpg
Square or portrait photos work best (cropped to a circle, face centred).
Until a photo is uploaded, the person's initials are shown instead.
For a sponsor logo, upload the file, then add its name in site-data.js,
for example: logo: "company.png".

CONTACT
The Contact page shows the chapter email address as a link. There is no
form to maintain. Change the address in site-data.js (email: "...").

CHAPTER EMAIL ADDRESSES
The role addresses (president@, secretary@ and so on) only work if mail
to them is delivered somewhere. If the domain is managed in Cloudflare,
its Email Routing feature can forward each address to a person's real
inbox. Set this up in the Cloudflare dashboard under the domain's Email
settings.

IF SOMETHING BREAKS
Undo your last change in site-data.js (most problems are a missing comma
or quote mark). GitHub keeps the history, so you can always go back.
